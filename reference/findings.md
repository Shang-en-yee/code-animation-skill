# 这套风格是怎么来的（结论摘要）

> 完整论文见工作区 `aesthetic-of-constraints/`。这里只留对制作有用的部分。

## 一句话

**风格是约束的下游，不是模型的签名。**

同一个模型能产出像素课堂、剪纸皮影、深空光轨、五分钟纪录片。决定长相的不是模型，是你给它的工具链限制。

## 四条约束 → 六条视觉特征

| 约束 | 因为它，所以 |
|---|---|
| 纯函数渲染（无跨帧状态） | 固定机位、固定节拍、元素只叠加不碰撞 |
| 无摄影、无素材 | 近黑底、发光而非投影、文字成为主角 |
| 浏览器矢量，单帧成本极低 | 低密度构图、发光（模糊副本比真光照便宜几个数量级） |
| 逐帧确定性输出 | 可重放、可局部重渲、可逐帧质检 |

## 这套美学"恰好避开"的东西

参考片和我们的片子都在规避模型的短板：

- 中间帧空间推理弱 → 单焦点，元素不相撞
- 长程状态一致性弱 → 纯函数，没有状态可漂移
- 长文本排版弱 → 一屏 ≤40 字
- 人物表演弱 → 剪影、贴图，或干脆不给人物
- 摄像机与 3D 调度弱 → 固定机位，运动都在画面内部

**"高级感"有一半来自"删掉了容易出错的东西"。**

## 可量化的部分

用三部片子校准过（一部参考片 + 我们两版）：

| 指标 | 参考片 | 本方案最终 |
|---|---|---|
| 帧间差 | 5.73 | 2.13 |
| 运动帧占比 | 91% | 100% |
| 结构覆盖率 | 33.6% | 54.9% |
| 平均亮度 | 41.6 | 18.6 |

参考片的数值被"2 倍速 + 高亮度"抬高，不必追平。**我们的覆盖率已经超过它。**

## 三个反直觉的经验

**1. "平坦区标准差"是个坏指标。**
它会奖励噪点，也受整体亮度影响。换成"结构覆盖率"（有多少像素参与了画面结构）才反映信息密度。

**2. 颗粒既是质感也是成本。**
它把运动指标拉起来，同时让文件大 4 倍。是一笔明账，要提前决定。

**3. 提亮比重构更有效。**
网格 alpha 从 0.16 提到 0.30，帧间差直接从 1.65 跳到 2.13。**之前所有"加了但看不见"的工作，都白做在亮度上。**

## 参考片失败的四个模式（做的时候避开）

来自 HeyGen × Kaggle 的 Code2Video 基准：

1. **时序错位**：新元素在旧动画没落定时就动
2. **飞行中碰撞**：只算终点，不算中间帧
3. **未完成的揭示**：打字机少一个字
4. **防御性布局**：不确定就把元素缩小、留白放大

我们的对策：一步一个入场、单焦点、终态断言、主视觉不小于画布 40%。

## 第四、五条经验（v4 补充）

**4. 不要测编码后的视频。**
同一份素材，mp4v 能测出 frame_diff 2.1，H.264 CRF23 只有 1.5——颗粒被编码器抹掉了。
一度以为片子变差了，其实只是换了编码器。**质检要测源帧。**

**5. 真 3D 的性价比很高。**
用同一个 `proj()` 把点放进三维空间、按深度排序、按距离调大小和透明度、再按焦点做假虚焦，视觉上的"体积感"立刻出来。
黑洞吸积盘和电梯舱两镜改完，是这一版观感提升最大的两处，代码量不到 200 行。
